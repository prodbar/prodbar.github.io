# Dataset

This project uses the Gen Z Mental Wellness & Digital Lifestyle Patterns dataset from Kaggle:

https://www.kaggle.com/datasets/hammadansari7/gen-z-mental-wellness-and-digital-lifestyle-patterns

The dataset contains 10,000 observations and 22 variables. The target variable is `Burnout_Risk`, with Low, Medium and High classes. Predictors describe digital lifestyle, wellbeing and personal context.

The local Excel file is:

```text
data/GenZ_dataset.xlsx
```

This file is ignored by Git until redistribution permission is explicitly confirmed. Public users should download the dataset directly from Kaggle and place it in this folder before running the notebook.
