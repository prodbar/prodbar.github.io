# Dataset

The raw Excel dataset is not intended to be committed until publication permissions are confirmed.

Local file used by the analysis:

```text
data/wind_energy_generation_spain_2020_2024.xlsx
```

The dataset contains Spanish wind power generation observations from January 2020 to December 2024. The R Markdown workflow aggregates the raw records into a monthly time series for forecasting analysis.
