# Time Series Forecasting of Wind Energy Generation in Spain

ARIMA-based forecasting and temporal analysis in R

## Project Overview

This completed coursework project analyzes monthly wind energy generation in Spain and develops forecasting models using R. The work combines temporal preprocessing, exploratory time series analysis, smoothing methods, ARIMA modeling and visual interpretation of forecasts.

## Objectives

- Prepare monthly wind power generation data for time series analysis.
- Explore trend, seasonality and residual structure in Spanish wind generation.
- Compare baseline exponential smoothing approaches with ARIMA-based models.
- Apply Box-Cox transformation and seasonal differencing where appropriate.
- Validate model adequacy through residual diagnostics.
- Generate interpretable forecasts for future wind energy generation.

## Dataset Description

The dataset contains Spanish wind power generation records from January 2020 to December 2024. The raw Excel file was provided for coursework and is kept locally in `data/`, but it is ignored by Git until publication permissions are confirmed.

See `data/README.md` for details.

## Methodology

The analysis uses a reproducible R Markdown workflow. It aggregates generation data to a monthly time series, explores the temporal pattern, applies STL decomposition, evaluates exponential smoothing models, and develops ARIMA models following a Box-Jenkins-style process.

The ARIMA workflow includes variance stabilization with Box-Cox transformation, seasonal differencing, ACF/PACF inspection, model comparison, parameter significance checks, residual diagnostics and forecast generation.
